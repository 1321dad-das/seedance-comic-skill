# 先定模式 再绑定职责
公开整理版：以下是制作与审查方法，不是模型功能保证；生成方案未经本包实测。

- 同一身份而允许新动作：主体参考，不自动继承原图姿势和场景。
- 只借色彩材质：风格参考，明确不采用供体身份。
- 站位空间：布局或场景参考，不等于固定第一帧。
- 必须从某画面开始：经检查的首帧，起姿可达动作目标。
- 起点终点均重要：相容的两端图；中间接触仍需计划与验收。
- 中间要经过特定状态：若当前入口支持，可用独立关键帧顺序，不是精确秒数锁帧。
- 借动作或运镜：选择供体职责，不把两者混用；固定目标机位与供体绕拍不能同时全部继承。
- 借声音：分别指定音色、台词、音乐或旋律职责；只借音色不默认继承供体台词、情绪和混响。参考不保证保留原录音、逐字零误差或永久声线。音频节奏不提供可见手脚路径与机位证据。[S3,S4]
- 白模重渲染：明确每个几何体映射；有视频输入不代表应选编辑任务。
- 延续已有视频：在入口支持原生延长时，明确母片、方向和实际边界。
- 以尾图生成新片：图片接力，不是原生延长；无完整速度或音轨继承保证。

当前 API 的专用首尾帧字段、普通参考字段及兼容组合需查实际文档。自然语言将普通图称首帧，不等于字段设置成功；多身份图加边界图应走确实支持的模式，不猜测字段可以拼接。

身份图负责是谁，已验收片尾状态负责此刻持物、朝向和站位。B已经接信就不能重演交接。选更早可用帧时记录截断点，不把它叫原始末帧。

首尾图的拉伸、裁剪及画幅处理未核实时，可先同画幅准备；具体行为仍须确认。冲突处理见[source-conflicts.md](source-conflicts.md)。

是否支持仅音频参考、需否搭配其他媒介以及输出类型，均按实际入口核验；制作文字可以先明确职责，不把其他版本或平台的组合规则移植过来。[S3,S5]
若要逐字原句，先分清保留字词还是保留既有录音演出；后者不能由参考能力承诺。若要卡点，先区分快慢起伏与准确拍点，以及音乐是否进入成片。无音频时不造BPM/时间码/编号；有素材后才测事件并合看画声。需要交接说明时，绑定与准备状态放正文外；只要正文时不强制附状态区，也不声称已验证，真实参考职责仍写清。[S4]

## 多格图只在时间语义不清时展开
先区分每格是完整镜头、同镜不同时刻、同一瞬间的角度候选，还是跳时/回忆。阅读顺序、放映顺序与故事发生顺序分别处理：换机位不证明时间前进，同机位也不证明连续拍摄。格子尺寸不等于时长，角度候选不自动变绕拍。[N19A,N19B]
已明确的跳时保留省略，回忆物件不写成现在的空间事实；不能为“连贯”补出被省略的坐起、进门或交接。格线、箭头与对白气泡先分清是制作说明还是成片内容。材料已说明就直接整理；未定且会改变剧情时先查既有注释，只在终稿必须选择而无授权时问最小决定，其他部分继续。三格同一时刻不变成三次事件。此为原创编译建议，非逐格执行保证。


动作片首帧还要核剧情阶段与实际姿势：已抵胸的胜负图不能靠“从对峙开始”文字变成低持起势。身份参考可另规划姿态；确实绑定首帧就从可见状态出发。需要接续与节奏排查时见[action-rhythm.md](action-rhythm.md)。
