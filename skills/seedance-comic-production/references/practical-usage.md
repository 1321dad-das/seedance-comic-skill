# 从需求到可提交正文
公开整理版：以下是制作与审查方法，不是模型功能保证；生成方案未经本包实测。

动作返修若涉及高成本试错，先读[成本与证据闸门](combat-workflow.md)，不把“优化提示”自动变成“再付费试一次”。

一次性任务优先免安装：在现有AI对话整理创作意图，再把正文放入用户实际使用的Seedance入口。参考绑定、设置选择和真实生成是独立步骤，不把文字完成说成已经提交。

收集任务类型、必须发生的动作因果与结果、角色和道具、逐字台词及语言、已提供素材和真实标签、总时长与画幅。缺项仅问必要问题；素材未收到时保留未绑定草案。用户给定的字面标签和映射原样保留，不按顺序重编号；交付允许说明时注明未观察素材、绑定未核实，只要正文时不强加说明或暗示已验证。

用户只要提示词时默认提供干净正文；需要执行交接或完整规划时，再按需提供四个分区，而不是强制四份文档：提示正文；设置清单；素材已收到/已观察/待提供/待绑定状态；少数最重要的成片风险（有几项写几项）。额外清单是制作交接，不是声称官方技能原本就输出这些。

不要将安装命令、版本号、SKILL全文或分析解释塞进视频正文。总时长与画幅放实际设置层；未要求时间轴时不自动编造秒表。

反复使用时先查现有宿主的加载方式，确认技能实际被发现。Claude Code、Codex、ChatGPT等调用方式与范围不同；本包的技能名不是已验证的平台原生命令，上传ZIP不代表自动安装。本文不执行安装、更新或联网命令。

原创建议请求：请只整理我的Seedance需求，保留人物、因果与台词，按需输出正文、设置、素材状态和主要风险。未见素材不假装观察，真实引用标签原样核对；不要新增未经要求的秒级分段或泛用画质词。
来源：source-catalog.md U1/U2与平台技能资料S7。宿主事实是查阅日快照，不等于用户账户已具备功能。

需要交接说明时，素材状态、来源和验收备注单列，不混入可复制正文；只要正文时不强制另附这些区块。精简正文时保留必要的谁、起点、信息触发、动作先后、逐字台词、终点、声音和参考职责；“抓稳后松手”不能压成没有条件的“抓住且松手”。用户明确给了时间段就保留，未给则不自动编秒表。
