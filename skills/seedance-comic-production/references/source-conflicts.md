# 官方资料冲突与未知项

本页提供冲突处理方法，不保留过期参数争议作为当前事实。

1. **先确认是否在说同一件事。** 区分模型发布、消费网页、API、账户套餐、任务模式、输入规格、输出规格和后处理；不同入口的数值不必相同。
2. **保留原始证据。** 记录两个链接、各自适用对象、资料日期与原文位置；检索更晚不代表页面更新更晚。不要编造修订原因或默默选择更大的上限。
3. **缩小依赖。** 首尾图处理未知可先准备同画幅图；音频组合未知可先写职责而不提交；不以自动升级、安装或付费测试填补文档缺口。
4. **明确执行阻断点。** 计费、素材授权、模式兼容或关键输出行为仍不确定时，暂停相关提交。文本创作、素材清单和验收计划可继续。
5. **以返回文件复核结果。** 编辑后比较目标、非目标区与接缝；延长后检查返回首尾与总长，确定是新增段还是整片，避免重复叠原片。音频另听，不能只看时长。
6. **不把观察升级为普遍规律。** 一次符合请求，不证明所有输入稳定；文档冲突也不自动证明模型缺陷。

记录模板：问题／适用入口与模式／来源 A／来源 B／一致与冲突部分／仍未知／安全准备／提交前必须解决的条件。官方入口见[来源目录](source-catalog.md)。
