# 入口与能力核验矩阵

本页是提交前检查表，不是固定参数表。即梦、火山方舟 API、Dreamina 等入口及同一入口的不同模型、账户、地区、任务模式可能不同；未查明就标未知，不从一个入口推断另一个入口。

| 项目 | 要记录的证据 | 不应外推 |
|---|---|---|
| 入口与模型 | 产品/接口、确切模型标识、文档版本、核查日期 | 产品名称相同不等于模型或账户权限相同 |
| 任务类型 | 文生视频、图像/视频参考、首尾帧、编辑、延长等当前支持模式 | 有视频输入不等于必须是编辑任务 |
| 输入与字段 | 文件类型、数量、体积、时长、角色字段、兼容组合 | 不把旧版参数或其他产品语法直接搬入 |
| 参考职责 | 身份、服装、场景、动作、机位、音色各由什么控制 | 参考不是永久身份锁或逐帧控制 |
| 时长与画幅 | 当前任务可选范围、自动选项、裁切/拉伸行为 | 剪辑目标时长不等于独立任务可提交时长 |
| 输出规格 | 请求档位、原始下载文件宽高帧率、音轨和已知后处理 | 输入分辨率与营销档位不证明原生输出规格 |
| 编辑与延长 | 修改范围、返回整片还是新增段、边界与音轨处理 | 不保证区间外像素不变，不推论无限延长 |
| 音频 | 可用参考组合、音色/音乐/台词职责、是否保留原录音 | 有音频参考不等于逐字、逐拍或波形复制 |
| 价格与权限 | 当前报价、计费单位、预览/Draft 费用、预算与上传授权 | 名为预览不代表免费；文档可见不代表账户开通 |
| 权利与限制 | 素材许可、肖像/声音同意、平台审核规则 | 不设计绕过平台身份或素材限制 |

## 核验顺序
1. 先查所选入口的当前官方文档，再对照实际账户界面或接口响应。
2. 明确资料日期、适用入口与任务模式；两处冲突时按[冲突处理](source-conflicts.md)保留未知。
3. 确认素材标签和字段真实生效后才称“已绑定”。自然语言里的标签不是接口成功回执。
4. 真正提交前重新确认报价和权限；有冲突或重要缺项时暂停依赖步骤，其他文字准备可继续。
5. 请求参数、实际返回元数据与观看结论分别记录。

模型能力入口见[公开资料目录](source-catalog.md) S1–S6。这些链接供继续核对，不表示本包已验证当前账户、生成质量或平台全部参数。提示中的引号、括号、@标签等均须按实际入口确认；不要把格式习惯当成保证执行的语法。
