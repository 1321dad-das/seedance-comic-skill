# 成本优先的动作返修流程
公开整理版：以下是制作与审查方法，不是模型功能保证；生成方案未经本包实测。

## 先分清创作与返修
要新场面的电影感、特效和景别设计，转读[仙侠导演设计](cinematic-combat.md)：先把想看的场面完整设计出来，再按本页决定是否及怎样试片。本页的低成本返修路线不是将所有仙侠打斗压成固定机位、近身素打或低特效。已有片返修仍先判断能否剪救，不擅自追加生成。

## 已认可的版本先保留
用户认为效果好又要求优化时，不沿用失败片的重做逻辑。先保存原版和认可点，按[分级精修](postproduction-qa.md)只挑有价值的问题；可选润色不冒充硬缺陷，证据不足不重抽。实际提交提示、参考和设置未知时仍标未知，不把已交付草案自动记为成功配方。保留用户接受的特效与风格，原版可继续作为主选；更新技能包不授权改片、上传或付费验证。

## 快速路线
要高速双人较量：先看目标样片与实际起始素材 → 确认是文字生成、图生视频还是视频编辑/参考 → 只标关键进攻路线、反应与衔接状态 → 用户需要提示时给有证据边界的简短草稿 → 实际生成另过成本闸门。普通对白、静戏不走这条动作返修路线。

## 先定位，不先加词或重抽
先从已有资料提取入口/模型、实际提交正文、参考用途和真实输出，缺什么才问什么。收到失败片不等于已收到实际提示；未核实处标未知，不把原因归咎用户或某个词。可以先交文字诊断或未绑定草案，不能称为已验证改进。
原速看相关动作段，分别诊断[节奏与运动连续性](action-rhythm.md)；记录最影响观感的一项证据和希望改变的结果。仅有静态资料时先审设计；有抽帧可定位姿态/停留线索，但未连续原速看片不能确认完整轨迹与“不丝滑”的具体成因。先检查剪出可用段/接点是否足够解决，不把每个瑕疵升级为重生成。

## 学别人时先过证据闸门
按[案例证据](combat-evidence.md)找相似动作、输入模式与镜头规模的原发布。优先能核对模型、输入/参考、实际提示和输出的案例；原发布者的“成功了”是声明，不是本次已看视频。公开视频若仅精选成片，也不证明原始单次输出或稳定复现。
有足够配对资料才讨论“这个案例展示了什么”；不够时交代缺口，最多列候选，不把它改名为已验证模板。即使看到同一提示与输出，也只说明一次关联，不证明该措辞造成改善；测试不同版本又没有控制其他因素，不作因果归因。

## 怎样把参考转成候选方案
先决定参考分工：例如经授权的视频只借动作路径，图像只借服装与场景；二者必须与本镜目标相容。参考标题中的“流畅”不是观看证据，真正采用前应检查其动作密度、起止状态、机位与后期情况。
草稿可先写整体意图，再保留关键转折，例如“甲推进，乙侧让并改变甲的运动方向，双方从这一结果继续”。这只是新写的结构示意，不是有效措辞证明。不要默认增加每秒时间轴、每个关节指令或重复禁慢词；用户锁定的时间安排仍须保留。
公开方法能提供候选，不提供本项目的失败分母、账户能力或复现保证。不能因某个创作者成功就承诺本镜适用。

## 方案选择按证据与成本排序
优先：复用已合格片段 → 剪辑/接点修复 → 参考已核案例做本镜候选 → 必要时提出有预算的关键动作试片。是否可用看实际片，不保证前三种总是便宜或有效。没有合格案例时明确“尚无可据以承诺的方案”，而不是拿更多强调词冒充研究成果。
动作参考视频若有用，先确认来源权利、与本镜适配、入口确实支持及用户允许上传；只说明借运动/运镜哪一项。不把真人表演、其他模型或Seedance其他版本的效果直接当当前目标模型的效果，也不认为视频参考必定更可靠。

## 若用户决定试片，先确定停止条件
助手先提最小有决策价值的测试：只验证当前关键难点，如一次进攻→避让/格挡→连续反应，而不是为测一处手剑关系生成整集。保留用户锁定内容；缩减范围只是验证方案，不偷偷改成片需求。
提交前记录确切入口/模型、预计计费方式、当次最高成本与总预算、允许尝试范围、验收点和停止条件；价格未知就先核，不估造。没有明确付费授权，停在方案交付。Draft/预览不自动等于免费；不推荐未经核实的低价模式替代用户所选模型。
- 关键动作已满足目标：保留结果，再决定是否值得扩展，不自动批量生成。
- 同一核心失败仍在且没有新证据/新假设：停止同词重抽，回到素材、构图、动作范围或技术可行性检查。
- 达到授权预算、输入绑定未确认、模型/报价改变：停止依赖步骤，给用户具体决定，不擅自加额。
- 新尝试需要时：说明它能区别哪种原因，预计代价及为何现有片不能解决；不因为“再试可能成功”自动继续。
这些是止损边界，不是暗示一次小样足够证明可靠。一次通过后如要稳定性证据，须另有明确价值与授权，保留所有输出和失败记录。

## 简短交接格式
现有证据与检查范围；主要问题；可不花生成费解决的部分；所学案例及证据等级；候选改动及不能保证的部分；若需付费则列待批准预算与停止条件。用户只要提示正文时保持正文干净，不附长表，但不能把未验证正文称为已验证方案。整场分镜可先规划，实际接续绑定等看片后核实。
