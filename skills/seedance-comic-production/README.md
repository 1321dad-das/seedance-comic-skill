# Seedance 漫剧制作技能包

**公开整理版 v1.9.9-public** · 基于 v1.9.9 制作文档整理。

这是供 AI 助手阅读的中文制作方法包：从故事、分镜、参考素材职责，到动作、镜头、声音、剪辑与验收。它不是视频模型、自动生成插件或安装器，不包含模型权重、账户、API 密钥、媒体素材或付费生成权限。

## 快速开始
1. 将本目录提供给能够读取 Markdown 的助手，请它先阅读 [SKILL.md](SKILL.md)。不必一次加载全部参考文档。
2. 说明故事目标、必须保留的角色与台词、已有素材，以及需要提示词、完整分镜还是实际制作方案。
3. 只有提示词需求时，先交简洁草案；素材不足时可保留未绑定草案，不假装已观察或绑定。
4. 真正生成前，独立核对所用入口、确切模型、输入模式、参数、权限和费用。实际上传、安装、付费、公开发布均需另有授权。
5. 有真实输出后才看片验收。文本检查、单帧与元数据不能代替完整视听。

可复制请求：
> 请按本包整理以下任务。故事目标：[填写]；必须保留的内容与逐字台词：[填写]；素材及各自用途：[填写或暂无]；需要的交付：[提示词／分镜／制作方案]；画幅与时长：[填写或请建议]；实际入口与模型：[已知则填]。保留我的创作意图，缺素材先给未绑定草案；不要声称看过或生成过，也不要自动上传或付费。

## 边界与许可
本包保留一般制作方法，移除非公开项目、反馈、检查记录与媒体细节。示例是新写的虚构情境，不对应真实用户作品。全部生成建议属于候选设计，不承诺稳定复现、口型准确、画质、速度或成本收益。
